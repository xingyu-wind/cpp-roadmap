# 计算机专业英语词汇表

> 适用路线：C++ 语法 → PowerShell / Git / VS Code → 数据结构 → 算法 → 计算机核心课程与就业。

## 使用方法

1. 不要从头到尾一次性背完，按当前学习阶段背。
2. 每次建议学习 10～20 个单词，先读音，再看中文，再结合代码或命令复习。
3. 已经在课程、报错、文件名里遇到过的词优先背。
4. 同一个单词在不同场景可能有不同含义，本表优先给出计算机语境中的意思。
5. 音标以常见美式读音为主。

## 自测标准

- 看到英文，能说出中文意思。

- 能在代码、终端或题目中认出该词。
- 能正确读出常用词，不要求一开始口音完美。
